# E.M.I.T. REST API Reference

**Base URL:** `http://localhost:8000/`  
**Protocol:** HTTP/1.1 (JSON UTF-8)  
**Authentication:** Environment-scoped / Session (Extensible for bearer auth)  
**OpenAPI / Swagger Documentation:** `http://localhost:8000/docs`

---

## 1. System Health & Status

### `GET /health`
Returns backend health status, database connectivity, and configured analysis providers.
* **Response 200 OK**:
```json
{
  "status": "healthy",
  "version": "1.0.0",
  "database": "connected",
  "providers": {
    "androguard": { "enabled": true, "available": true },
    "scapy": { "enabled": true, "available": true },
    "mobsf": { "enabled": false, "available": false },
    "tshark": { "enabled": false, "available": false }
  }
}
```

## 2. Cases Management

### `POST /cases`
Registers a new forensic investigation case.
* **Request Body**:
```json
{
  "name": "Operation Cobalt Droid",
  "description": "Analysis of suspicious banking dropper communicating with external C2"
}
```
* **Response 201 Created**: Returns created `Case` object with unique `case_id`.

### `GET /cases`
Retrieves all registered forensic cases.
* **Response 200 OK**: Array of `Case` objects sorted by `created_at` descending.

### `GET /cases/{case_id}`
Retrieves metadata for a specific case.
* **Response 200 OK**: `Case` object.
* **Response 404 Not Found**: If case does not exist.

### `DELETE /cases/{case_id}`
Deletes a case and all associated evidence files, observations, correlations, and reports.
* **Response 200 OK**: `{"message": "Case deleted successfully"}`.

## 3. Evidence Management

### `POST /cases/{case_id}/evidence`
Uploads and validates an APK or PCAP evidence binary for a case.
* **Content-Type**: `multipart/form-data`
* **Form Parameters**: `file` (Binary payload)
* **Validations**:
  * Enforces magic bytes (`PK\x03\x04` for APK, libpcap or PCAPNG headers for captures).
  * Enforces `MAX_EVIDENCE_SIZE_BYTES` (500 MB limit).
  * Computes cryptographic SHA-256 server-side.
  * Rejects duplicate file hashes within the same case context with HTTP 409 Conflict.
* **Response 201 Created**: `EvidenceFile` record.

### `GET /cases/{case_id}/evidence`
Lists all uploaded evidence files associated with a case.
* **Response 200 OK**: Array of `EvidenceFile` objects.

### `GET /cases/{case_id}/evidence/{evidence_id}`
Retrieves metadata for a specific evidence item.
* **Response 200 OK**: `EvidenceFile` object.

### `DELETE /cases/{case_id}/evidence/{evidence_id}`
Deletes an evidence file from storage and unlinks associated metadata.
* **Response 200 OK**: `{"message": "Evidence deleted successfully"}`.

## 4. Analysis Jobs & Pipeline Execution

### `POST /cases/{case_id}/evidence/{evidence_id}/analyze`
Dispatches an analysis job for a specific evidence file.
* **Query Parameters**: `analysis_type` (`STATIC_APK` | `NETWORK_PCAP`)
* **Response 202 Accepted**: `{"analysis_id": "uuid...", "status": "PENDING"}`.

### `GET /cases/{case_id}/runs`
Lists all analysis execution jobs for a case.
* **Response 200 OK**: Array of `AnalysisRun` objects detailing per-provider status and execution metrics.

## 5. Normalized Forensic Entities & Workspace Queries

### `GET /cases/{case_id}/indicators`
Lists all normalized indicators (IOCs) extracted across all evidence items in the case.
* **Response 200 OK**: Array of `Indicator` objects.

### `GET /cases/{case_id}/observations`
Retrieves all atomic evidence observations (ground-truth facts).
* **Response 200 OK**: Array of `Observation` objects with source tool and authentic timestamp.

### `GET /cases/{case_id}/correlations`
Retrieves synthesized cross-evidence correlations generated by the deterministic correlation engine.
* **Response 200 OK**: Array of `Correlation` objects with deductive reasons and supporting evidence IDs.

### `GET /cases/{case_id}/graph`
Retrieves the complete attack chain graph topology.
* **Response 200 OK**:
```json
{
  "nodes": [
    {
      "node_id": "node-1",
      "node_type": "APPLICATION",
      "label": "com.malware.dropper",
      "entity_reference": "com.malware.dropper"
    }
  ],
  "edges": [
    {
      "edge_id": "edge-1",
      "source_node_id": "node-1",
      "target_node_id": "node-2",
      "relationship_type": "CONNECTS_TO",
      "relationship_class": "CORRELATED",
      "strength": "STRONG",
      "reason": "APK embeds domain observed in PCAP DNS queries",
      "supporting_evidence_ids": ["ev-1", "ev-2"]
```

## 6. Threat Intelligence & Risk Assessment

### `POST /cases/{case_id}/threat-intel/enrich`
Triggers external threat intelligence enrichment on all relevant indicators (domains, IPs, hashes) across enabled providers.
* **Response 200 OK**: Array of `ThreatIntelResult` objects with verdict and score.

### `GET /cases/{case_id}/threat-intel`
Retrieves stored threat intelligence enrichment records for a case.
* **Response 200 OK**: Array of `ThreatIntelResult` objects.

### `GET /cases/{case_id}/risk`
Computes and returns the deterministic risk assessment.
* **Response 200 OK**:
```json
{
  "case_id": "case-uuid",
  "risk_level": "CRITICAL",
  "confidence_score": 0.85,
  "risk_score": 92.0,
  "summary": "Multiple high-risk indicators observed: hardcoded C2 domain matching DNS lookups...",
  "observed_facts": ["APK embeds domain evil.com", "PCAP contains 14 outbound DNS queries"],
  "analytical_inferences": ["Coordinated communication chain between APK and external infrastructure"],
  "uncertainty_limitations": ["TLS payload encryption prevents deep inspection of POST parameters"],
  "analyst_guidance": ["Inspect certificate pins in decompiled classes", "Perform WHOIS query on domain"]
}
```

## 7. Reports & Dossier Export

### `POST /cases/{case_id}/reports/generate`
Compiles an official forensic investigation dossier.
* **Request Body**:
```json
{
  "format": "BOTH",
  "title": "Operation Cobalt Droid Forensic Dossier"
}
```
* **Supported Formats**: `HTML`, `PDF`, `BOTH`.
* **Response 201 Created**: `Report` record with download paths and cryptographic SHA-256 hashes.

### `GET /cases/{case_id}/reports`
Lists all compiled reports for a case.
* **Response 200 OK**: Array of `Report` records.

### `GET /cases/{case_id}/reports/{report_id}/download`
Streams the generated report document.
* **Query Parameters**: `format` (`html` | `pdf`)
* **Response 200 OK**: Binary document stream with `Content-Disposition: inline` or `attachment`.
